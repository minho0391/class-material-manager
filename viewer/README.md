# 수업자료 뷰어

수집·정리한 수업자료와 공식 문서 요약을 브라우저에서 읽기 위한 화면입니다.

## 실행

```bash
cd viewer
npm install     # 처음 한 번만
npm run dev     # → http://localhost:3000
```

CLI 로 자료를 다시 수집한 뒤에는 **브라우저 새로고침만** 하면 됩니다.
`data/index.json` 의 갱신 시각이 바뀌면 뷰어가 알아서 자료를 다시 읽습니다.

## 읽기 전용입니다

이 뷰어는 자료를 **보여주기만** 합니다.

| 확인 항목 | 상태 |
|---|---|
| 파일을 쓰는 코드 | **없음** (`writeFile`·`unlink`·`rename` 등 0건) |
| API 라우트 | **없음** — 쓰기 요청을 받을 통로 자체가 없습니다 |
| 파일 접근 | `readFile`·`readdir` 만 사용 |
| 경로 안전 | 주소로 들어온 값을 `index.json` 에 등록된 것과 **대조**한 뒤에만 파일을 엽니다 |

마지막 항목이 중요합니다. 주소창의 값을 그대로 파일 경로로 쓰면 `../../` 같은 값으로
엉뚱한 파일을 열 수 있는데, 카탈로그에 없는 값은 파일을 열어보지도 않고 없는 것으로 처리합니다.

## 화면

```
┌──────────────┬─────────────────────────────────────┐
│ react    127 │  # 자료 제목                         │
│ css       78 │  [과목] [섹션] [쪽수]                │
│ javascript 58│                                      │
│  └ jquery 15 │  📘 이 주제의 공식 문서               │
│ html      17 │     · Function (MDN)                 │
│ nextjs    18 │                                      │
│ typescript 13│  ...본문...                          │
│ 그 밖의 자료  │                                      │
└──────────────┴─────────────────────────────────────┘
```

| 주소 | 화면 |
|---|---|
| `/` | 홈 — 전체 규모와 과목 카드 |
| `/s/[과목]` | 과목별 목록 (수업자료 + 공식 문서 요약을 나란히) |
| `/m/[docId]` | 수업자료 상세 |
| `/r/[과목]/[문서]` | 공식 문서 요약 상세 |
| `/search?q=` | 검색 |

## 검색

**제목과 본문을 함께** 찾습니다. 546건의 본문을 서버가 시작할 때 한 번 읽어 두므로
검색할 때마다 파일을 다시 열지 않습니다.

수업자료와 공식 문서 요약에 각각 40건씩 제한을 둡니다.
전체에 하나의 제한을 걸면 수업자료가 자리를 다 차지해 공식 문서가 한 건도 안 보이게 됩니다.

## 구조

```
viewer/
├── app/
│   ├── layout.tsx              바깥 틀 (테마 + 사이드바)
│   ├── page.tsx                홈
│   ├── s/[subject]/page.tsx    과목별 목록
│   ├── m/[docId]/page.tsx      수업자료 상세
│   ├── r/[subject]/[slug]/     공식 문서 요약 상세
│   └── search/page.tsx         검색
├── components/
│   ├── AppShell.tsx            AppBar + 사이드바
│   ├── Markdown.tsx            마크다운 렌더링
│   └── nav.tsx                 ★ 링크 부품 (아래 설명 참고)
└── lib/
    ├── data.ts                 ★ 자료를 읽는 유일한 통로
    └── theme.ts                색과 글꼴
```

### `components/nav.tsx` 가 따로 있는 이유

MUI 부품은 전부 브라우저에서 도는 **클라이언트 컴포넌트**인데,
페이지(`page.tsx`)는 서버에서 도는 **서버 컴포넌트**입니다.
서버에서 클라이언트로 **함수를 넘길 수 없어서** 아래처럼 쓰면 오류가 납니다.

```tsx
// ❌ page.tsx 안에서
<ListItemButton component={NextLink} href="/...">
```

`nav.tsx` 는 맨 위에 `"use client"` 가 붙어 통째로 브라우저 쪽입니다.
여기서 `NextLink` 를 미리 연결해 두면 페이지에서는 그냥 가져다 쓰면 됩니다.

```tsx
// ✅ page.tsx 안에서
<NavListItem href="/...">
```
